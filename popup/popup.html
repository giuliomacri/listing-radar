      New to this? Step-by-step guide
      1. Open Telegram and start a chat with BotFather (the official bot, with a blue check).
      2. Send /newbot. Pick a name, then a username that ends in bot.
      3. BotFather replies with a long message. Under "Use this token to access the HTTP API" is your Token API, like 123456:ABC…. Copy it and paste it into "Token API" below (pasting the whole message also works).
      4. Open your new bot in Telegram (BotFather gave you a t.me/… link), press Start and send it any message, for example "hi". This is how the extension learns where to send alerts.
      5. Come back here, tick Enabled and press Save. The extension finds your chat id by itself. Then press Send test.

      Tip: make a new bot for this extension instead of reusing another one. Never share the token with anyone.
